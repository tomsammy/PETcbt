# PETcbt - Kwara State Office of the Head of Service CBT Evaluation System

An interactive Computer-Based Testing (CBT) web application built for the **Kwara State Office of the Head of Service** Productivity Enhancement Evaluation.

## ✨ Features

- **Candidate Intake & Verification**: Direct registration with Officer Full Name, Public Service Number (PSN), Email Address, and Grade Level Cadre (`GL 06-07`, `GL 08`, `GL 09`).
- **20-Minute Live Countdown Timer**: High-visibility digital countdown with real-time seconds countdown and color transitions (Warning at $\le$ 5 minutes, Danger/Pulsing at $\le$ 2 minutes), plus dual indicator on the Question Palette sidebar.
- **Auto-Submission**: When the 20-minute countdown concludes, answers are automatically finalized and submitted.
- **Strict Single-Attempt Rule**: Each PSN is permitted only one exam attempt. Re-entry attempts are immediately blocked with a clear notice.
- **Real-Time Grading & Official Result Slip**: Instant score calculation (50 questions $\times$ 2 marks = 100 marks), performance remark, and printable/downloadable result slip.
- **Admin Management Portal**: Authenticated admin dashboard with roster analytics, live search/filtering, and one-click Excel (`.xlsx`) and CSV spreadsheet exports.
